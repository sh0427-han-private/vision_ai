P4 · 06 DOT PRODUCT

Dot Product: 곱하고 모두 더하기

입력의 대응 원소를 곱해 더한 결과가 Scalar 32임을 검산합니다.

기초 수학예상 학습 16분수치 예시 · 직접 그린 도식

왜 Dot Product를 배우는가?

Dot Product (대응 원소의 곱을 더한 내적)(내적)는 길이가 같은 두 벡터의 대응 원소끼리 곱한 뒤 전부 더하는 연산입니다. 예를 들어 입력 [1,2,3]과 가중치 [4,5,6]을 합치면 결과는 Scalar 하나입니다. Kernel의 원소별 곱·합이나 Matrix Multiplication도 이 계산을 반복합니다.

단계별 수치 검산

\[\begin{aligned}\mathbf{a}\cdot\mathbf{b}&=1\cdot4+2\cdot5+3\cdot6\\&=4+10+18=32\end{aligned}\]
위치곱누적 합
01×4 = 44
12×5 = 1014
23×6 = 1832
조건

두 벡터의 길이가 같아야 합니다. Dot Product는 원소별 곱 배열이 아니라 곱의 합인 Scalar를 반환합니다.

재현 가능한 Python

Python 3 표준 라이브러리 예제 — 아래 셀은 독립 실행할 수 있습니다.

a = [1, 2, 3]
b = [4, 5, 6]
assert len(a) == len(b)
print(sum(x * y for x, y in zip(a, b)))

예상 출력: 32. 실제 학습 모델의 출력이 아닌 고정 예제입니다.

연결 학습

  • 선수 Vector
  • Matrix Multiplication
  • Spatial Kernel

아직 독립 페이지가 없는 연관 개념: Cosine Similarity (학습 계획이며 클릭 가능한 링크로 제공하지 않습니다).
