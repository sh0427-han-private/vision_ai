P4 · 03 MATRIX

Matrix: 행과 열, 그리고 곱셈

2차원 행렬의 shape와 두 행렬의 곱을 직접 계산합니다.

기초 수학예상 학습 18분수치 예시 · 직접 그린 도식

행(row)과 열(column)

Matrix (행과 열에 배치된 2차원 수치 배열)(행렬)는 행과 열로 수치를 배치합니다. [[1,2],[3,4]]는 2행 2열(shape [2,2])입니다. 각 행은 길이 2의 벡터이고, 열도 두 개 존재합니다. 행렬의 곱은 원소별 곱이 아니라 왼쪽 행 × 오른쪽 열의 Dot Product입니다.

Matrix Multiplication 수동 검산

\[\displaystyle \begin{bmatrix}1&2\\3&4\end{bmatrix}\begin{bmatrix}2&0\\1&2\end{bmatrix}=\begin{bmatrix}4&4\\10&8\end{bmatrix}\]
출력 원소행 × 열값
C[0,0]1×2 + 2×14
C[0,1]1×0 + 2×24
C[1,0]3×2 + 4×110
C[1,1]3×0 + 4×28
Shape 계약

일반적으로 [m,k] @ [k,n] → [m,n]입니다. 안쪽 k가 일치하지 않으면 행렬곱은 정의되지 않습니다.

재현 가능한 Python

Python 3 표준 라이브러리 예제 — 아래 셀은 독립 실행할 수 있습니다.

a = [[1, 2], [3, 4]]
b = [[2, 0], [1, 2]]
c = [[sum(a[i][k] * b[k][j] for k in range(2))
      for j in range(2)] for i in range(2)]
print(c)

예상 출력: [[4, 4], [10, 8]]. 실제 학습 모델의 출력이 아닌 고정 예제입니다.
