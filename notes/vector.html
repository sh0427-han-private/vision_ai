P4 · 02 VECTOR

Vector: 순서 있는 수치들

원소·축·차원을 구분하고 벡터의 길이를 수치로 검산합니다.

기초 수학예상 학습 14분수치 예시 · 직접 그린 도식

Vector의 원소와 좌표

Vector (순서 있는 수치 성분으로 표현하는 벡터)(벡터)는 숫자를 순서대로 놓아 만든 수학적 객체입니다. 예를 들어 [3,4]는 2차원 벡터이며 숫자 3과 4가 각각 두 축의 성분입니다. 이때 수학의 벡터 차원과 배열의 축 개수(rank)를 혼동하지 않습니다. 리스트 [3,4]는 길이 2의 1축 배열입니다.

위치 벡터 (3,4)는 원점에서 x 방향 3, y 방향 4만큼 이동한 화살표로 생각할 수 있습니다.

원소·축·길이 계산

\[\displaystyle \|\mathbf v\|_2=\sqrt{3^2+4^2}=\sqrt{25}=5\]
입력처리출력
[3, 4]3² + 4² = 25, 제곱근5
[1, 2, 3]원소 개수3
조건

두 벡터를 원소별로 더하려면 같은 좌표계와 호환되는 차원이 필요합니다.

재현 가능한 Python

Python 3 표준 라이브러리 예제 — 아래 셀은 독립 실행할 수 있습니다.

v = [3, 4]
length = sum(x * x for x in v) ** 0.5
print(length)

예상 출력: 5.0. 실제 학습 모델의 출력이 아닌 고정 예제입니다.
