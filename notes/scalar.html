P4 · 01 SCALAR

Scalar: 값 하나에서 시작하기

한 개의 수, 자료형, 단위를 구분하고 다른 개념의 입력값으로 연결합니다.

기초 수학예상 학습 12분수치 예시 · 직접 그린 도식

Scalar는 왜 필요한가?

Scalar (하나의 수와 단위를 구분하는 수치 개념)(스칼라)는 하나의 수치입니다. 이미지 밝기 한 값이나 학습률, 길이와 같은 양을 표현할 수 있지만, 값이 하나라고 단위까지 자동으로 정해지지는 않습니다. 예를 들어 5는 정수(int)일 수 있고 5.0은 부동소수점(float)일 수 있습니다.

입력 → 처리 → 출력: 거리 5 m와 시간 2 s → 나누기 → 평균 속력 2.5 m/s. 두 값을 같은 단위의 숫자로 취급하지 않고 양과 단위를 함께 기록합니다.

값·자료형·단위 계산

\[\displaystyle v=\frac{5\,\mathrm{m}}{2\,\mathrm{s}}=2.5\,\mathrm{m/s}\]
양값자료형·단위
거리5.0float · m
시간2.0float · s
속력2.5float · m/s
주의

동일한 숫자라도 단위가 다르면 직접 더할 수 없습니다. float의 소수 표현에는 반올림 오차가 생길 수 있습니다.

재현 가능한 Python

Python 3 표준 라이브러리 예제 — 아래 셀은 독립 실행할 수 있습니다.

distance_m = 5.0
seconds = 2.0
print(distance_m / seconds)

예상 출력: 2.5. 실제 학습 모델의 출력이 아닌 고정 예제입니다.
