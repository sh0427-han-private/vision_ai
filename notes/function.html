Function: 입력과 출력을 연결하기

선형·Affine·비선형 함수를 구분하고 출력값을 직접 계산합니다.

기초 수학예상 학습 16분수치 예시 · 직접 그린 도식

Function(함수)은 무엇을 하는가?

Function (입력값을 출력값에 대응시키는 규칙)(함수)는 입력을 정해진 규칙에 따라 출력으로 변환하는 대응입니다. 같은 입력에는 같은 출력이 나와야 하는 일반적인 결정적 함수 예시를 먼저 봅니다. f(x)=2x는 선형(linear), g(x)=2x+1은 상수항이 있는 Affine, h(x)=max(0,x)는 ReLU 비선형 함수입니다.

MLP와 CNN의 Activation은 여러 층이 단순한 하나의 Affine 변환으로 합쳐지는 것을 막고 복잡한 대응을 학습하게 합니다.

선형·Affine·ReLU의 출력 비교

\[\begin{aligned}f(x)&=2x\\g(x)&=2x+1\\h(x)&=\max(0,x)\end{aligned}\]

재현 가능한 Python

Python 3 표준 라이브러리 예제 — 아래 셀은 독립 실행할 수 있습니다.

f = lambda x: 2*x
g = lambda x: 2*x + 1
h = lambda x: max(0, x)
print(f(-2), g(-2), h(-2))

예상 출력: -4 -3 0. 실제 학습 모델의 출력이 아닌 고정 예제입니다.
