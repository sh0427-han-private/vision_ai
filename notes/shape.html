P4 · 05 SHAPE

Shape·Dimension·Axis: 숫자의 위치를 읽기

축의 순서를 실제로 바꿔도 18개 값이 보존되는지 확인합니다.

기초 수학예상 학습 18분수치 예시 · 직접 그린 도식

Shape는 무엇을 정하는가?

Shape (각 축의 길이를 기록하는 튜플)(형상)는 축별 길이를 모아 놓은 튜플입니다. Dimension(차원)은 문맥에 따라 축 수 또는 축 길이를 뜻할 수 있으므로 모호하면 rank=축 수, axis=축 번호, size=해당 축 길이로 분리해 적습니다.

이미지 HWC (2,3,3)은 높이 2, 너비 3, 채널 3이며 총 18개 원소입니다. 채널을 첫 축으로 옮긴 CHW는 (3,2,3)입니다. 같은 18개 값이라도 요소의 위치를 바르게 옮기려면 transpose를 사용합니다.

Reshape와 Transpose를 구분

\[\begin{aligned}(H,W,C)&=(2,3,3)\\(C,H,W)&=(3,2,3)\\\text{axis order}&=(2,0,1)\end{aligned}\]
연산shape의미
HWC 시작[2,3,3]h,w,c
CHW = transpose[3,2,3]c,h,w
원소 개수2×3×3 = 3×2×3 = 18값 수 동일
중요

reshape는 데이터 배열을 다른 크기로 해석할 뿐 HWC 축을 CHW로 바꾸지 않습니다. transpose/permute가 필요합니다.

18개 값 보존 검산

Python 3 표준 라이브러리 예제 — 아래 셀은 독립 실행할 수 있습니다.

hwc = [[[9*h + 3*w + c for c in range(3)]
        for w in range(3)] for h in range(2)]
chw = [[[hwc[h][w][c] for w in range(3)]
        for h in range(2)] for c in range(3)]
print((len(chw), len(chw[0]), len(chw[0][0])))
print(chw[0][0], sum(len(row) for plane in chw for row in plane))

예상 출력:

(3, 2, 3)
[0, 3, 6] 18

실제 학습 모델의 출력이 아닌 고정 예제입니다.
